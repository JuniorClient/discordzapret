Открыть релизы

Где скачать сборку

Файлы готовых выпусков размещаются в разделе Releases. Перед скачиванием сверьте назначение пакета, поддерживаемую систему и инструкции к выбранному релизу. Наличие репозитория само по себе не означает, что готовый архив уже опубликован.

Подготовка к запуску

  1. Откройте документацию в репозитории и описание выбранного выпуска.
  2. Выберите файл для своей системы, если автор его опубликовал.
  3. Распакуйте архив целиком в отдельную папку, сохраняя вложенные компоненты.
  4. Сверьте имена сценариев с содержимым пакета и прочитайте их перед запуском.
  5. Следуйте инструкции именно этого выпуска. Запишите исходные настройки, чтобы изменения можно было отменить.

Проверка подключения Discord

Проверьте вход, текстовые сообщения, вложения и голос отдельно. Открытие окна приложения не подтверждает работу всех видов соединения.

Если голосовой канал зависает на RTC Connecting, сравните приложение и браузер в одинаковых условиях. Если канал подключился, но микрофон не слышен, отдельно проверьте устройства ввода и разрешения. Меняйте один параметр за раз и сохраняйте точный результат.

Вопросы и ответы

Где находятся файлы для скачивания?

Откройте раздел Releases репозитория JuniorClient/discordzapret. Готовые архивы доступны там после публикации автором; исходный код и готовый пакет могут отличаться.

Где смотреть инструкцию по запуску?

Используйте README и описание именно выбранного выпуска в репозитории. Названия сценариев и параметры нельзя переносить из другой сборки только из-за похожего названия.

Что проверить после настройки?

Отдельно проверьте вход в Discord, отправку сообщения, загрузку вложения и подключение к голосовому каналу. Запишите точную ошибку, если она осталась.

Что делать при RTC Connecting?

Сравните приложение и браузер при одинаковой конфигурации, попробуйте другой голосовой канал. Меняйте один параметр за раз и сохраняйте результат проверки; по одному симптому нельзя установить причину.
